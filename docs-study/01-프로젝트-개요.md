# ZK-DEX 프로젝트 개요

## 프로젝트란?

ZK-DEX는 **영지식 증명(Zero-Knowledge Proof)** 기반의 **탈중앙화 거래소(DEX)**입니다.

핵심 특징:
- 거래 금액, 소유자 정보를 공개하지 않고 토큰을 교환
- ZK-SNARK(Groth16)를 사용해 온체인에서 증명 검증
- Bitcoin의 UTXO와 유사한 "노트(Note)" 시스템 사용

---

## 디렉토리 구조

```
zk-dex/
├── circuits-circom/     # ZK 회로 (Circom 2.1)
│   ├── main/            # 6개의 메인 회로
│   ├── utils/           # 유틸리티 회로 (Poseidon, BabyJubJub 등)
│   └── scripts/         # 빌드 스크립트
│
├── contracts/           # Solidity 스마트 컨트랙트 (0.8.20)
│   ├── ZkDex.sol        # 메인 DEX 컨트랙트
│   ├── ZkDai.sol        # 노트 관리 (mint, spend, liquidate)
│   ├── ZkDaiBase.sol    # 기본 컨트랙트 (상태, 매핑)
│   └── verifiers/       # Groth16 검증자 (snarkjs 생성)
│
├── scripts/lib/         # JavaScript 유틸리티
│   ├── noteProofHelper.js  # 증명 생성 메인 API
│   ├── snarkjsUtils.js     # snarkjs 래퍼
│   └── Note.js             # Note 클래스
│
├── vapp/                # Vue 3 프론트엔드
│   ├── src/components/  # Vue 컴포넌트
│   ├── src/lib/         # 클라이언트 암호화 라이브러리
│   ├── src/stores/      # Pinia 상태 관리
│   └── src/workers/     # Web Worker (증명 생성)
│
├── test/                # 테스트 (93개 통과)
└── docs/                # 기존 문서
```

## 기술 스택

| 레이어 | 기술 |
|--------|------|
| **블록체인** | Ethereum (Solidity 0.8.20, Truffle) |
| **ZK 증명** | Circom 2.1.0, snarkjs 0.7.x |
| **증명 시스템** | Groth16 (BN128 곡선) |
| **암호화** | Poseidon 해시, BabyJubJub 타원곡선 |
| **프론트엔드** | Vue 3, Pinia, Vite, TypeScript |
| **블록체인 연동** | ethers.js 6.x |

---

## 핵심 연산 6가지

| 연산 | 설명 | 회로 |
|------|------|------|
| **Mint** | ETH/DAI 입금 → 노트 생성 | `mint_burn_note` |
| **Liquidate** | 노트 소각 → ETH/DAI 출금 | `mint_burn_note` |
| **Transfer** | 프라이빗 전송 (금액 비공개) | `transfer_note` |
| **Make Order** | 거래 주문 생성 | `make_order` |
| **Take Order** | 주문 수락 (스테이크) | `take_order` |
| **Settle Order** | 주문 체결 (원자적 스왑) | `settle_order` |

---

## 프라이버시 보장 수준

| 연산 | 금액 | 소유자 |
|------|------|--------|
| Mint/Liquidate | **공개** (입출금 검증 필요) | 비공개 |
| Transfer | **비공개** | **비공개** |
| Order 관련 | 비공개 (가격만 공개) | 부분 공개 |

**핵심**: Transfer는 금액과 소유자 모두 완전히 비공개!

## 빠른 시작

```bash
# 의존성 설치
npm install
cd circuits-circom && npm install && cd ..
cd vapp && npm install && cd ..

# 테스트 (다른 터미널에서 Ganache 시작 필요)
npx ganache --port 8545
npx truffle test

# Docker로 전체 스택 실행
docker compose up ganache vapp-api vapp -d
# 접속: http://localhost:8080
```
