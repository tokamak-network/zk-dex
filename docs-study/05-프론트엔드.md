## 핵심 라이브러리 (src/lib/)

### 1. circuitLoader.ts

회로 파일(wasm, zkey)을 로드합니다.

```typescript
// 매니페스트 로드
const manifest = await loadManifest()
// { circuits: { mint_burn_note: { wasm: '...', zkey: '...' }, ... } }

// 특정 회로 로드
const { wasm, zkey } = await loadCircuit('mint_burn_note')
```

### 2. proofGenerator.ts

ZK 증명을 생성하는 메인 API입니다.

```typescript
// 초기화 (Poseidon, BabyJubJub 로드)
await proofGenerator.init()

// 키 생성
const { sk, pk } = await proofGenerator.generateKeypair()

// 노트 생성
const note = await proofGenerator.createNote(sk, value, tokenType)

// 증명 생성
const proof = await proofGenerator.generateMintProof(note, sk)
const proof = await proofGenerator.generateTransferProof(old0, old1, new0, new1, sk0, sk1)
const proof = await proofGenerator.generateMakeOrderProof(note, sk)
// ...

// 증명 결과
// { a: [...], b: [[...], [...]], c: [...], input: [...] }
```

### 3. Note.ts

Note 클래스입니다.

```typescript
class Note {
  owner0: bigint   // pkX
  owner1: bigint   // pkY
  value: bigint
  tokenType: bigint
  vk0: bigint      // = pkX
  vk1: bigint      // = pkY
  salt: bigint

  hash(): bigint {
    return poseidon([owner0, owner1, value, tokenType, vk0, vk1, salt])
  }

  toCircuitInput(): object { ... }
}
```

### 4. noteEncryption.ts

ECDH + AES-256-GCM 암호화입니다.

```typescript
// 암호화 (수신자 공개키로)
const encrypted = await encryptNote(note, recipientPk)
// 결과: 0x01 || epk || nonce || ciphertext || authTag

// 복호화 (자신의 비밀키로)
const note = await decryptNote(encrypted, sk)
```

## 상태 관리 (Pinia Stores)

### account.ts (ZK 계정)

```typescript
const accountStore = useAccountStore()

// 계정 생성
await accountStore.createAccount(password)

// 계정 잠금 해제
await accountStore.unlockAccount(password)
// → sk가 메모리에 로드됨

// 계정 내보내기/가져오기
const keystore = accountStore.exportKeystore()
await accountStore.importKeystore(keystore, password)
```

### note.ts (노트 관리)

```typescript
const noteStore = useNoteStore()

// 내 노트 목록
noteStore.myNotes  // Note[]

// 노트 생성
await noteStore.mint(value, tokenType)

// 노트 전송
await noteStore.transfer(note, recipientPk, amount)

// 노트 소각 (출금)
await noteStore.liquidate(note, toAddress)
```

### order.ts (주문 관리)

```typescript
const orderStore = useOrderStore()

// 주문 목록
orderStore.orders  // Order[]

// 주문 생성
await orderStore.makeOrder(note, targetToken, price)

// 주문 수락
await orderStore.takeOrder(orderId, myNote)

// 주문 체결
await orderStore.settleOrder(orderId)
```

### wallet.ts (MetaMask)

```typescript
const walletStore = useWalletStore()

// 지갑 연결
await walletStore.connect()

// 상태
walletStore.address      // 이더리움 주소
walletStore.isConnected  // 연결 상태
walletStore.provider     // ethers.js Provider
```

## Web Worker (증명 생성)

증명 생성은 CPU 집약적이므로 Web Worker에서 실행하여 UI가 멈추지 않도록 합니다.

```typescript
// workers/proofWorker.ts
self.onmessage = async (e) => {
  const { type, data } = e.data

  if (type === 'generateProof') {
    const { circuitName, input } = data
    const { wasm, zkey } = await loadCircuit(circuitName)

    // snarkjs 증명 생성 (WASM)
    const { proof, publicSignals } = await snarkjs.groth16.fullProve(
      input, wasm, zkey
    )

    self.postMessage({ proof, publicSignals })
  }
}
```

**사용:**

```typescript
const worker = new Worker(new URL('./workers/proofWorker.ts', import.meta.url))

worker.postMessage({
  type: 'generateProof',
  data: { circuitName: 'mint_burn_note', input }
})

worker.onmessage = (e) => {
  const { proof, publicSignals } = e.data
  // 컨트랙트에 제출
}
```

D3.js를 사용하여 노트 전송 트리를 SVG로 시각화합니다.

```vue

    <!-- D3가 렌더링 -->
  </svg>

<script setup>
import { useNoteTreeLayout } from '@/composables/useNoteTreeLayout'

const { renderTree } = useNoteTreeLayout(svgRef)

watch(notes, () => {
  renderTree(notes)
})
```

## 증명 생성 흐름

```
1. 사용자 액션 (예: Mint 버튼 클릭)
        ↓
2. proofGenerator.generateMintProof(note, sk)
        ↓
3. Web Worker로 작업 전달
        ↓
4. circuitLoader가 wasm/zkey 로드
        ↓
5. snarkjs.groth16.fullProve() 실행
        ↓
6. 증명 포맷팅 (Solidity용)
        ↓
7. ethers.js로 컨트랙트 호출
        ↓
8. 온체인 검증 (Groth16 verifier)
```
