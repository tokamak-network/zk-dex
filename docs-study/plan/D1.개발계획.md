D1 비밀 투표 (Private Voting) 개발 계획

 개요

 ZK-DEX 프로젝트에 D1 비밀 투표 기능을 추가합니다.
 - 커밋-리빌 방식의 비밀 투표
 - 투표 선택은 숨기고, 투표력만 공개
 - ~150K 제약 조건 (mint_burn_note와 유사)

 결정 사항

 - 노트 연동: 기존 ETH/DAI 노트 사용 (노트 잔액 = 투표력)
 - 프론트엔드: 최소 데모 (1개 페이지, 2-3개 컴포넌트)

 ---
 Phase 1: 회로 개발

 1.1 머클 증명 유틸리티 추가

 새 파일: circuits-circom/utils/merkle/merkle_proof.circom

 - 스냅샷 머클 트리 포함 증명
 - TREE_DEPTH = 20 (약 100만 개 노트 지원)
 - circomlib의 poseidon 사용

 1.2 비밀 투표 회로 작성

 새 파일: circuits-circom/main/private_voting.circom

 공개 입력 (4개):

 ┌────────────────┬──────────────────────────────────┐
 │      입력      │               설명               │
 ├────────────────┼──────────────────────────────────┤
 │ voteCommitment │ 투표 선택 + salt의 해시 커밋먼트 │
 ├────────────────┼──────────────────────────────────┤
 │ proposalId     │ 제안 ID                          │
 ├────────────────┼──────────────────────────────────┤
 │ votingPower    │ 투표력 (노트 잔액, 공개)         │
 ├────────────────┼──────────────────────────────────┤
 │ merkleRoot     │ 스냅샷 머클 루트                 │
 └────────────────┴──────────────────────────────────┘

 
 비공개 입력:
 - pkX, pkY, sk (소유권)
 - noteHash, noteValue, noteSalt (노트)
 - choice, voteSalt (투표)
 - merklePath[20], merkleIndex (머클 증명)

 재사용할 기존 유틸리티:
 - utils/poseidon/poseidon_note.circom → PoseidonNote
 - utils/babyjubjub/proof_of_ownership.circom → ProofOfOwnershipStrict
 - circomlib/circuits/comparators.circom → LessThan
 - circomlib/circuits/poseidon.circom → Poseidon

 1.3 회로 컴파일

 # compile.sh에 private_voting 추가
 cd circuits-circom
 npm run compile private_voting
 npm run setup private_voting
 npm run generate-verifiers

 수정할 파일: circuits-circom/scripts/compile.sh
 - CIRCUITS 배열에 "private_voting" 추가

 Phase 2: 스마트 컨트랙트 개발

 2.1 투표 컨트랙트

 새 파일: contracts/PrivateVoting.sol

 struct Proposal {
     bytes32 merkleRoot;      // 스냅샷 머클 루트
     uint256 startTime;       // 투표 시작
     uint256 commitDeadline;  // 커밋 마감
     uint256 revealDeadline;  // 리빌 마감
     uint256 forVotes;        // 찬성 투표력
     uint256 againstVotes;    // 반대 투표력
     uint256 abstainVotes;    // 기권 투표력
     bool finalized;
 }

 mapping(uint256 => Proposal) public proposals;
 mapping(bytes32 => bool) public nullifiers;  // 이중 투표 방지
 mapping(bytes32 => bytes32) public commitments;  // 커밋 저장

 주요 함수:
 1. createProposal(merkleRoot, duration) - 제안 생성
 2. commitVote(proposalId, proof, voteCommitment) - 투표 커밋
 3. revealVote(proposalId, choice, voteSalt, votingPower) - 투표 공개
 4. finalizeProposal(proposalId) - 결과 집계

 2.2 검증자 컨트랙트

 개발 순서

 1. 회로 개발 (Phase 1)
    ├── 머클 증명 유틸리티
    ├── 비밀 투표 회로
    └── 컴파일 & 검증자 생성

 2. 컨트랙트 개발 (Phase 2)
    ├── PrivateVoting.sol
    └── 배포 스크립트

 3. 테스트 (Phase 3)
    ├── 회로 단위 테스트
    ├── 컨트랙트 단위 테스트
    └── 통합 테스트

 4. 프론트엔드 (Phase 4)
    ├── 스토어 & 증명 생성
    ├── 컴포넌트
    └── 페이지 & 라우팅

 E2E 시나리오

 4. 리빌 기간에 투표 공개
 5. 마감 후 결과 확인
