B1 시간 잠금 노트 (Time-Locked Notes) 개발 계획

 개요

 ZK-DEX 프로젝트에 B1 시간 잠금 노트 기능을 추가합니다.
 - 특정 시간 이후에만 사용 가능한 노트
 - 잠금 해제 시간, 금액, 수취인 모두 비공개
 - ~150K 제약 조건

 핵심 유즈케이스

 - 비밀 베스팅 스케줄 (직원 토큰 부여)
 - 익명 유산 상속
 - 기밀 투자 락업

 Phase 1: 회로 개발

 1.1 시간 잠금 노트 해시 유틸리티

 새 파일: circuits-circom/utils/poseidon/poseidon_timelock_note.circom

 // 시간 잠금 노트 해시 (8개 입력)
 // hash(pkX, pkY, value, tokenType, salt, unlockTime, lockType, vk)
 // lockType = 0: 시간 잠금
 template PoseidonTimeLockNote() {
     signal input pkX, pkY;
     signal input value, tokenType;
     signal input salt, unlockTime;
     signal input lockType;  // 0 = time-lock
     signal input vk;        // viewing key (pkX와 동일)
     signal output out;
 }

 1.2 시간 잠금 노트 생성 회로

 새 파일: circuits-circom/main/create_timelock.circom

 공개 입력 (4개):
 ┌────────────┬──────────────────────────┐
 │    입력    │           설명           │
 ├────────────┼──────────────────────────┤
 │ noteHash   │ 시간 잠금 노트 해시      │
 ├────────────┼──────────────────────────┤
 │ value      │ 노트 가치                │
 ├────────────┼──────────────────────────┤
 │ tokenType  │ 토큰 타입 (0=ETH, 1=DAI) │
 ├────────────┼──────────────────────────┤
 │ unlockTime │ 잠금 해제 타임스탬프     │
 └────────────┴──────────────────────────┘
 비공개 입력:
 - pkX, pkY, sk (소유권)
 - salt (노트 무작위성)

 회로 로직:
 1. 소유권 검증 (sk → pk)
 2. 시간 잠금 노트 해시 계산 및 검증

 1.3 시간 잠금 노트 사용 회로

 새 파일: circuits-circom/main/spend_timelock.circom

 공개 입력 (4개):
 ┌─────────────┬────────────────────────────┐
 │    입력     │            설명            │
 ├─────────────┼────────────────────────────┤
 │ noteHash    │ 입력 시간 잠금 노트 해시   │
 ├─────────────┼────────────────────────────┤
 │ outputHash  │ 출력 일반 노트 해시        │
 ├─────────────┼────────────────────────────┤
 │ currentTime │ 컨트랙트의 block.timestamp │
 ├─────────────┼────────────────────────────┤
 │ tokenType   │ 토큰 타입                  │
 └─────────────┴────────────────────────────┘
 비공개 입력:
 - pkX, pkY, sk (소유권)
 - value, salt, unlockTime (입력 노트)
 - outPkX, outPkY, outSalt (출력 노트)

 회로 로직:
 1. 입력 노트 해시 검증
 2. 소유권 검증
 3. 시간 조건 검증: currentTime >= unlockTime
 4. 출력 노트 해시 계산 (일반 노트로 변환)

 재사용할 기존 유틸리티:
 - utils/poseidon/poseidon_note.circom → PoseidonNote (출력용)
 - utils/babyjubjub/proof_of_ownership.circom → ProofOfOwnershipStrict
 - circomlib/circuits/comparators.circom → LessThan (시간 비교)

 1.4 회로 컴파일

 수정할 파일: circuits-circom/scripts/compile.sh
 CIRCUITS=(
     ...
     "create_timelock"
     "spend_timelock"

 Phase 2: 스마트 컨트랙트 개발

 2.1 시간 잠금 컨트랙트

 새 파일: contracts/TimeLock.sol

 // SPDX-License-Identifier: MIT
 pragma solidity ^0.8.0;

 import {ICreateTimeLockVerifier, ISpendTimeLockVerifier} from "./verifiers/IGroth16Verifier.sol";
 import "./ZkDaiBase.sol";

 contract TimeLock is ZkDaiBase {
     ICreateTimeLockVerifier public createVerifier;
     ISpendTimeLockVerifier public spendVerifier;

     // 시간 잠금 노트 추적
     mapping(bytes32 => uint256) public noteUnlockTimes;

     event TimeLockCreated(bytes32 indexed noteHash, uint256 unlockTime);
     event TimeLockSpent(bytes32 indexed inputNote, bytes32 indexed outputNote);

     // 시간 잠금 노트 생성 (ETH/DAI 예치)
     function createTimeLock(
         uint256[2] calldata a,
         uint256[2][2] calldata b,
         uint256[2] calldata c,
         uint256[5] calldata input,  // [out, noteHash, value, tokenType, unlockTime]
         bytes calldata encryptedNote
     ) external payable;

     // 시간 잠금 노트 사용 (잠금 해제 후)
     function spendTimeLock(
         uint256[2] calldata a,
         uint256[2][2] calldata b,
         uint256[2] calldata c,
         uint256[5] calldata input,  // [out, noteHash, outputHash, currentTime, tokenType]
         bytes calldata encryptedNote
     ) external;
 }

 2. 노트 선택 후 잠금 해제 시간 설정 (예: 1분 후)

 ---
 주의사항

 시간 검증

 - block.timestamp는 채굴자가 ~15초 범위 내에서 조작 가능
 - 분/시간 단위 세분성 권장 (초 단위 정밀도 불필요)

 노트 형식 호환성

 - 시간 잠금 노트는 기존 PoseidonNote와 다른 해시 구조
 - lockType 필드로 노트 타입 구분
 - 지갑에서 별도 추적 필요
