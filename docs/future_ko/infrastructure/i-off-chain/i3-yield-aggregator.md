# I3. 수익률 집계자

포지션이나 전략을 노출하지 않고 최고 수익률 기회로 자금을 이동하는 프라이버시 보존 수익률 최적화 인프라.

**요구사항**: 비공개 수익률 추적 | 전략 암호화 | 자동 리밸런싱 | 가스 최적화 실행

---

## 배경

DeFi 수익률 최적화는 심각한 프라이버시 문제에 직면합니다:

- **전략 노출**: 눈에 보이는 수익 파밍이 수익성 있는 전략을 모방자에게 공개
- **포지션 투명성**: 공개 포지션은 선행매매 및 복사 초대
- **TVL 신호**: 대규모 입금/출금이 전략 변경을 신호
- **경쟁적 침식**: 눈에 보이는 알파는 빠르게 차익거래됨

비공개 수익률 집계는 다음을 통해 이를 해결합니다:
- 프로토콜 전반의 포지션 크기 숨기기
- 전략 결정 및 리밸런싱 로직 암호화
- 프라이버시 보존 인프라를 통한 이동 실행
- 운영 보안을 통한 경쟁 우위 유지

ZK-DEX의 경우, 이는 보호된 알파로 정교한 수익률 전략을 가능하게 합니다.

## 기술 사양

### 아키텍처 개요

```
예금자                         수익률 집계자                    DeFi 프로토콜
+--------+                    +------------------------+          +------------+
|        |  비공개 예금       |                        |          |            |
|사용자 1|------------------>|  전략 엔진             |--------->| 프로토콜 A |
|        |                    |  (암호화된 로직)       |          | (Aave)     |
+--------+                    |         |              |          +------------+
|        |  비공개 예금       |         v              |          |            |
|사용자 2|------------------>|  +----------------+    |--------->| 프로토콜 B |
|        |                    |  | 수익률 모니터  |    |          | (Compound) |
+--------+                    |  | (비공개 피드)  |    |          +------------+
                              |  +----------------+    |          |            |
                              |         |              |--------->| 프로토콜 C |
                              |         v              |          | (Yearn)    |
                              |  리밸런싱 엔진         |          +------------+
                              |  (숨겨진 이동)         |
                              +------------------------+
```

### 컴포넌트 목록

| 컴포넌트 | 설명 |
|-----------|-------------|
| **예금 볼트** | 예금 수락; 비공개 지분 토큰 발행 |
| **수익률 모니터** | 프로토콜 전반의 수익률을 비공개로 추적 |
| **전략 엔진** | 할당 결정을 위한 암호화된 로직 |
| **리밸런서** | 노출 없이 포지션 변경 실행 |
| **성과 추적기** | 포지션을 공개하지 않고 수익률 계산 |
| **지분 회계** | 입금/출금을 위한 공정 가치 계산 |

### 데이터 흐름

1. **예금 흐름**
   - 사용자가 볼트에 자산 예금
   - 비공개 지분 토큰 수신 (ZK 커밋먼트)
   - 볼트가 수익률 기회에 할당

2. **전략 실행**
   - 수익률 모니터가 기회 식별
   - 전략 엔진이 할당 결정
   - 리밸런서가 비공개 채널을 통해 자금 이동

3. **출금 흐름**
   - 사용자가 ZK 증명으로 지분 소유권 증명
   - 비례적 자산 상환
   - 볼트 전략이나 다른 포지션 노출 없음

### 수익률 전략 회로

```circom
pragma circom 2.1.0;

include "../utils/poseidon/poseidon.circom";
include "../utils/comparators.circom";

template YieldAllocation(numProtocols) {
    // 공개 입력
    signal input totalValueCommitment;  // 총 볼트 가치에 대한 커밋먼트
    signal input allocationCommitment;  // 할당에 대한 커밋먼트
    signal input timestamp;

    // 비공개 입력
    signal input allocations[numProtocols];  // 각 프로토콜의 금액
    signal input yields[numProtocols];       // 프로토콜당 현재 APY
    signal input riskScores[numProtocols];   // 위험 등급
    signal input salt;

    // 총 가치 계산
    signal totalValue;
    signal runningTotal[numProtocols + 1];
    runningTotal[0] <== 0;
    for (var i = 0; i < numProtocols; i++) {
        runningTotal[i + 1] <== runningTotal[i] + allocations[i];
    }
    totalValue <== runningTotal[numProtocols];

    // 총 가치 커밋먼트 검증
    component tvHash = Poseidon(3);
    tvHash.inputs[0] <== totalValue;
    tvHash.inputs[1] <== timestamp;
    tvHash.inputs[2] <== salt;
    tvHash.out === totalValueCommitment;

    // 할당 커밋먼트 검증
    component allocHash = Poseidon(numProtocols + 1);
    for (var i = 0; i < numProtocols; i++) {
        allocHash.inputs[i] <== allocations[i];
    }
    allocHash.inputs[numProtocols] <== salt;
    allocHash.out === allocationCommitment;

    // 가중 수익률 계산 (전략 최적화용)
    signal weightedYield[numProtocols];
    signal totalYield;
    signal yieldSum[numProtocols + 1];
    yieldSum[0] <== 0;
    for (var i = 0; i < numProtocols; i++) {
        weightedYield[i] <== allocations[i] * yields[i];
        yieldSum[i + 1] <== yieldSum[i] + weightedYield[i];
    }
    totalYield <== yieldSum[numProtocols];
}

component main {public [totalValueCommitment, allocationCommitment, timestamp]} = YieldAllocation(10);
```

## 효과

| 측면 | 영향 |
|--------|--------|
| **전략 프라이버시** | 경쟁자로부터 할당 로직 숨김 |
| **포지션 프라이버시** | 개별 프로토콜 포지션이 보이지 않음 |
| **알파 보호** | 수익성 있는 전략이 쉽게 복사되지 않음 |
| **가스 효율성** | 배치 리밸런싱이 사용자당 비용 감소 |
| **수익률 최적화** | 최고 기회로 지속적 이동 |
| **위험 관리** | 노출 없이 비공개 위험 한도 |

## 보안 고려사항

| 위험 | 완화 |
|------|------------|
| **전략 유출** | 암호화된 실행; 신뢰할 수 있는 인프라 |
| **프로토콜 위험** | 다각화 한도; 위험 점수 평가 |
| **비영구적 손실** | LP 포지션 회피 또는 헤지; 명확한 공개 |
| **스마트 컨트랙트 위험** | 감사된 프로토콜만; 보험 커버리지 |
| **출금 러시** | 유동성 준비금; 단계별 출금 |
| **관리자 부정행위** | 시간 잠금 전략 변경; 거버넌스 감독 |

## 구현 과제

1. **교차 프로토콜 프라이버시**
   - 외부 프로토콜 예금이 눈에 보임
   - 예금을 위한 믹서 또는 릴레이 네트워크 필요
   - 프로토콜 네이티브 프라이버시 기능 고려

2. **수익률 데이터 정확성**
   - APY 계산이 프로토콜마다 다름
   - 표준화된 측정 필요
   - 시간 가중 수익률 고려

3. **리밸런싱 비용**
   - 가스 비용이 수익률 차이를 초과할 수 있음
   - 임계값 기반 리밸런싱 필요
   - 효율성을 위해 사용자 작업 배치

4. **전략 복잡성**
   - 단순 전략은 더 빨리 복사됨
   - 복잡한 전략은 정교한 인프라 필요
   - 복잡성과 투명성 균형

5. **유동성 관리**
   - 일부 수익률 포지션은 비유동적
   - 출금을 위한 유동성 버퍼 필요
   - 계층별 출금 타이밍 고려

## 파생상품

1. **위험 조정 수익률** - 위험 조정 수익률로 기회 가중. 더 높은 위험에서 더 높은 수익률 할인. Sharpe 비율 최적화를 비공개로.

2. **전략 볼트** - 다양한 전략의 여러 볼트. 보수적, 균형적, 공격적 옵션. 사용자가 위험 프로필 선택; 전략은 숨김.

3. **자동 복리** - 수익률 자동 재투자. 수동 조치 없이 복리 이자. 가스 효율적 배치 수확.

4. **교차 프로토콜 마이그레이션** - 수익률 변경에 따라 프로토콜 간 포지션 이동. 사용자 조치 없이 원활한 리밸런싱. 비공개 마이그레이션 경로.

5. **수익률 토큰화** - 미래 수익률 스트림 토큰화. 원금과 별도로 수익률 거래. 수익률 투기를 비공개로 가능.

## 사용 사례

1. **수동적 수익률 최적화**
   - 사용자가 최고 수익률을 찾는 스테이블코인 예금
   - 집계자가 대출 프로토콜 간 이동
   - 사용자가 적극적 관리 없이 최적 수익률 획득
   - 전략 세부정보가 모방자로부터 숨김

2. **기관 수익률 전략**
   - 펀드가 DeFi 수익률 기회에 할당
   - 포지션이 경쟁자로부터 숨김
   - 포지션 공개 없이 성과 보고
   - 경쟁 우위 유지

3. **재무 관리**
   - DAO 재무가 준비금으로 수익률 획득
   - 할당 전략이 공개되지 않음
   - 대규모 이동의 선행매매 방지
   - 게이밍 없이 지속 가능한 수익률

4. **위험 관리 노출**
   - 사용자가 위험 한도로 수익률 원함
   - 집계자가 프로토콜당 최대 노출 집행
   - 위험 이벤트 시 자동 리밸런싱
   - 한도를 공개하지 않는 위험 관리

## 실제 제품 및 사용자 경험

### 1. "숨겨진 예금 규모" - 예치 금액 완전 비공개

**제품 설명**:
수익률 최적화 서비스에 얼마를 예치했는지 외부에서 알 수 없는 프라이버시 볼트. 자산 규모로 타겟이 되는 것을 방지합니다.

**일반 사용자 경험**:
- 한미영씨(33세)는 $100,000를 DeFi에 예치하려 함
- 일반 볼트: "이 주소가 $100K 예치" 공개 → 피싱 타겟
- 프라이빗 볼트: commitment만 기록, 금액은 숨김
- 외부에서는 "누군가 예치함"만 알고 금액 모름
- 미영씨가 고액 예치자라는 사실 자체가 비공개

**관찰 가능한 이점**:
- 자산 규모로 피싱/해킹 타겟 방지
- "부자 주소" 라벨링 회피
- 대량 예치자 식별 차단

### 2. "전략 배분 비공개" - 어디에 투자했는지 숨김

**제품 설명**:
수익률 최적화 전략이 어느 프로토콜에 얼마나 배분했는지 외부에 공개되지 않아 전략 복제를 방지하는 서비스.

**일반 사용자 경험**:
- 김투자씨(48세)는 "Alpha 전략 볼트"에 $50,000 예치
- 일반 볼트: "이 볼트가 Aave 40%, Compound 30%..." 공개
- 비공개 볼트: 배분 내역이 암호화되어 ZK로만 검증
- 경쟁자가 "이 볼트 전략을 따라하자" 불가능
- 전략 매니저의 알파가 보호됨

**관찰 가능한 이점**:
- 수익률 높은 전략의 복제 방지
- 지속 가능한 초과수익 유지
- 매니저의 지적재산권 보호

### 3. "리밸런싱 은닉" - 전략 변경 신호 차단

**제품 설명**:
볼트가 프로토콜 간 자금을 이동할 때 이동 내역이 공개되지 않아 "시장 신호"를 주지 않는 프라이버시 리밸런싱.

**일반 사용자 경험**:
- 안전 볼트가 프로토콜 A에서 B로 $1M 이동 예정
- 일반 이동: "대형 볼트가 A에서 빠진다" → A 프로토콜 FUD
- 프라이빗 이동: 이동 금액과 경로가 숨겨진 채 실행
- 시장에서 "볼트가 이동 중"이라는 신호 없음
- 리밸런싱이 시장에 영향을 주지 않음

**관찰 가능한 이점**:
- 대형 이동이 시장 신호가 되지 않음
- 리밸런싱 의도 (리스크 회피?) 숨김
- 프로토콜 간 자금 흐름 추적 차단
