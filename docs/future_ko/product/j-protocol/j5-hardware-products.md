## 제품 시나리오

### 1. "로컬 프루빙" - 데이터가 기기를 떠나지 않음

**제품명**: 클라이언트 사이드 증명 생성 시스템

**제품 설명**:
사용자 기기의 GPU/CPU에서 직접 증명을 생성하여 거래 데이터가 외부 서버로 전송되지 않는 완전 프라이버시 프루빙. 민감한 거래 정보가 로컬에서만 처리됩니다.

**일반 사용자 경험**:
이게이머(26세, 프로 게이머)는 민감한 대량 아이템 거래를 실행할 예정입니다.

- **문제 상황**: 일반 ZK 시스템은 증명 생성을 외부 프루버 서비스에 의존합니다. 사용자는 거래 데이터(위트니스)를 프루버 서버로 전송해야 하므로, "누군가 내 거래 내용을 볼 수 있다"는 우려가 있습니다. 프루버 운영자가 악의적이거나 해킹당하면 거래 내용이 노출될 수 있습니다.

- **로컬 프루빙 사용**: 이씨의 RTX 4080 GPU를 활용하여 기기에서 직접 증명을 생성합니다. 거래 데이터(금액, 상대방, 아이템 내역)는 절대 기기 밖으로 나가지 않으며, 오직 최종 증명만 네트워크에 제출됩니다. 증명 자체는 거래 내용을 포함하지 않습니다.

- **결과**: 이씨는 외부 서비스를 신뢰할 필요 없이 완전한 프라이버시를 확보합니다. "어떤 아이템을 얼마에 거래하는지" 정보가 자신의 기기 밖으로 전혀 나가지 않으므로, 프루버 관련 위험이 제로입니다.

**관찰 가능한 이점**:
- **거래 데이터의 완전한 로컬 처리**: 외부 전송 제로
- **프루버 서비스 신뢰 불필요**: 자체 하드웨어로 프라이버시 보장
- **자신의 하드웨어로 프라이버시 보장**: 제3자 위험 제거

### 2. "TEE 보호 프루빙" - 프루버 운영자도 모름

**제품명**: 신뢰실행환경 증명 생성 서비스

**제품 설명**:
TEE(Trusted Execution Environment)가 탑재된 하드웨어에서 증명을 생성하여 프루버 운영자조차 거래 내용을 볼 수 없는 인프라. 외부 서비스 이용과 프라이버시를 양립합니다.

**일반 사용자 경험**:
사용자가 빠른 증명 생성을 위해 외부 프루버 서비스를 이용하고 싶어 합니다.

- **문제 상황**: 로컬 프루빙은 완벽한 프라이버시를 제공하지만, 개인 GPU로는 느립니다. 외부 프루버 서비스는 빠르지만, 프루버 서버 관리자가 기술적으로 거래 데이터에 접근할 수 있어 프라이버시 우려가 있습니다.

- **TEE 프루버 사용**: 사용자의 암호화된 거래 데이터가 프루버 서버의 TEE(예: Intel SGX, AMD SEV) 내에서만 복호화되고 처리됩니다. TEE는 하드웨어 레벨에서 보호되므로, 프루버 서버 관리자도 TEE 내부 데이터에 접근할 수 없습니다. 증명 생성 후 TEE 내 데이터는 즉시 삭제됩니다.

- **결과**: 사용자는 외부 고속 인프라의 이점(5초 증명 생성)과 완전한 프라이버시를 동시에 얻습니다. 프루버 운영자도 "어떤 거래인지" 알 수 없으므로, 인프라 신뢰 문제가 해결됩니다.

**관찰 가능한 이점**:
- **외부 서비스 이용 시에도 데이터 비공개**: TEE로 관리자 접근 차단
- **인프라 신뢰 문제 해결**: 하드웨어 보안으로 보장
- **속도와 프라이버시의 양립**: 고성능과 프라이버시 동시 달성

### 3. "프라이버시 우선 모바일" - 폰에서 완전 비공개 거래

**제품명**: 모바일 GPU 증명 생성 앱

**제품 설명**:
모바일 GPU를 활용해 스마트폰에서 직접 증명을 생성하여 거래 정보가 어떤 서버에도 전송되지 않는 완전 자급자족 프라이버시 거래. 네트워크로 전송되는 것은 증명뿐입니다.

**일반 사용자 경험**:
박프라이버시(30세, 프라이버시 중시 사용자)는 이동 중 민감한 거래를 실행합니다.

- **문제 상황**: 모바일에서 외부 프루버를 사용하면 Wi-Fi/LTE를 통해 거래 데이터가 전송됩니다. 통신사나 중간 네트워크가 데이터 패킷을 감청할 수 있으며, 프루버 서버로의 전송 경로에 여러 노출 지점이 있습니다.

- **모바일 프루빙 사용**: 박씨의 스마트폰(예: Galaxy S24, iPhone 15)의 모바일 GPU를 활용하여 폰 내에서 모든 처리를 완료합니다. 거래 데이터는 폰 메모리에서만 존재하고, 네트워크로 전송되는 것은 오직 최종 256바이트 증명뿐입니다. 증명 자체는 거래 내용을 포함하지 않습니다.

- **결과**: 박씨는 어디서든(지하철, 카페, 해외 여행) 네트워크 레벨 프라이버시를 확보합니다. 통신사 감청, 공공 Wi-Fi 위험, 프루버 서버 해킹 모두로부터 안전하며, 거래 내용은 오직 자신의 폰에만 존재합니다.

**관찰 가능한 이점**:
- **네트워크 레벨 프라이버시 확보**: 전송 데이터에 거래 정보 없음
- **통신 감청에도 거래 내용 보호**: 패킷 분석으로 내용 파악 불가
- **어디서든 완전한 프라이버시**: 네트워크 환경에 무관한 보안
