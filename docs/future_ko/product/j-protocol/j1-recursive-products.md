## 제품 시나리오

### 1. "패턴 숨김 배치" - 여러 거래를 하나로 합쳐 개별 분석 방지

**제품명**: 거래 패턴 난독화 서비스

**제품 설명**:
수천 건의 프라이빗 거래를 재귀 증명으로 압축하여 개별 거래 패턴 분석이 불가능하게 만드는 프라이버시 강화 서비스. 개인의 거래 빈도, 타이밍, 행동 패턴을 대규모 익명 세트 속에 완전히 숨깁니다.

**일반 사용자 경험**:
김거래씨(32세, 전문 트레이더)는 하루 평균 50건의 프라이빗 거래를 실행합니다.

- **문제 상황**: 개별 증명 방식에서는 "오전 10시에 5건, 오후 2시에 8건, 오후 5시에 15건" 등 거래 패턴이 시간별로 관찰 가능합니다. 비록 거래 내용은 숨겨져도, 거래 빈도와 타이밍으로 "이 사용자는 시장 마감 전 집중 거래하는 전략"이라는 분석이 가능합니다.

- **패턴 숨김 배치 사용**: 김씨의 50건 거래가 다른 9,950명의 거래와 함께 하나의 재귀 증명으로 압축됩니다. 10,000건의 거래가 하나의 증명으로 제출되므로, 외부에서는 "이 배치에 10,000건이 있다"는 것만 알 수 있을 뿐 어느 거래가 김씨의 것인지 전혀 구분할 수 없습니다.

- **결과**: 김씨는 자신의 거래 빈도, 타이밍 선호도, 활동 패턴을 완전히 숨길 수 있습니다. 경쟁 트레이더들이 "이 전략은 시장 마감 전 집중 거래" 같은 패턴 분석을 할 수 없게 됩니다.

**관찰 가능한 이점**:
- **개별 사용자 거래 패턴 분석 불가**: 거래 빈도와 타이밍으로 사용자를 프로파일링할 수 없음
- **대규모 익명 세트에서 프라이버시 강화**: 10,000명 중 1명으로 섞여 식별 불가능
- **타이밍 상관관계 분석 차단**: "시장 이벤트와 거래 타이밍 연관성" 분석 불가

### 2. "크로스롤업 프라이버시 허브" - 롤업 간 자산 흐름 숨김

**제품명**: 멀티체인 프라이버시 집계 인프라

**제품 설명**:
여러 롤업의 증명을 집계할 때 어느 롤업에서 어느 롤업으로 자산이 이동했는지 추적이 불가능하게 만드는 프라이버시 허브. 롤업 간 자금 흐름을 숨겨 크로스체인 추적과 MEV를 방지합니다.

**일반 사용자 경험**:
박멀티씨(28세, DeFi 파워유저)는 여러 롤업을 오가며 최적의 수익률을 추구합니다.

- **문제 상황**: 일반 롤업 집계에서는 "롤업 A에서 10 ETH 출금, 롤업 B로 9.8 ETH 입금" 같은 흐름이 시간 분석으로 추적 가능합니다. 크로스롤업 MEV 봇들이 이런 이동 패턴을 감지하고 공격합니다. 또한 "이 사용자는 A, B, C 롤업 모두 사용"하는 전체 활동이 노출됩니다.

- **프라이버시 허브 사용**: A, B, C 세 롤업의 상태 변경이 모두 하나의 재귀 증명으로 집계됩니다. 증명은 "A, B, C 롤업의 상태 전환이 모두 유효함"만 증명하지, 롤업 간 자금 흐름은 집계 내부에서 완전히 숨겨집니다.

- **결과**: 박씨가 A에서 B로 자산을 이동해도, 외부에서는 "A 롤업에서 누군가 출금, B 롤업에 누군가 입금" 정도만 알 수 있을 뿐 이 둘이 연결되었는지 알 수 없습니다. 크로스롤업 추적과 MEV가 원천 차단됩니다.

**관찰 가능한 이점**:
- **멀티롤업 사용자의 전체 활동 숨김**: 어떤 롤업들을 사용하는지 프로필 생성 불가
- **롤업 간 자산 흐름 분석 차단**: "A에서 B로 이동" 연결고리 제거
- **크로스롤업 트래킹 방지**: 체인 간 사용자 활동 추적 불가능

### 3. "시간 윈도우 난독화" - 거래 시점 정보 제거

**제품명**: 타이밍 프라이버시 폴딩 서비스

**제품 설명**:
재귀 증명으로 폴딩할 때 개별 거래의 정확한 타이밍 정보가 제거되어 "언제 거래했는지" 분석이 불가능한 서비스. 행동 패턴의 시간 분석을 완전히 차단합니다.

**일반 사용자 경험**:
이게이머(22세, 블록체인 게임 플레이어)는 경쟁 게임에서 실시간 아이템 거래를 합니다.

- **문제 상황**: 일반 배치 시스템에서는 "이 거래는 블록 #12345에 포함" 같은 타이밍 정보로 "3시 15분 전후에 거래 발생"을 추론할 수 있습니다. 경쟁자들이 "이 플레이어는 게임 보스 출현 직후 아이템을 판다"는 행동 패턴을 분석하여 전략을 간파합니다.

- **시간 난독화 사용**: 재귀 폴딩 과정에서 개별 거래의 타이밍 정보가 점진적으로 제거됩니다. 최종 증명에는 "이 기간 동안 N건의 거래가 있었다"는 정보만 남고, 각 거래의 정확한 시점은 복구 불가능해집니다.

- **결과**: 이씨의 아이템 거래 타이밍이 보호됩니다. 경쟁자들은 "보스 출현 후 30분 내 거래" 같은 시간 패턴 분석을 할 수 없으므로, 게임 전략이 노출되지 않습니다.

**관찰 가능한 이점**:
- **거래 시점 기반 분석 차단**: 타이밍으로 행동 패턴 추론 불가
- **활동 시간대 프라이버시 보호**: "주로 저녁에 활동" 같은 프로필 방지
- **실시간 활동 모니터링 방지**: 현재 활동 상태 파악 불가능
