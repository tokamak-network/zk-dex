## 1. "일회용 결제 주소 생성기" - 매번 새로운 주소로 받기

**제품 설명**:
하나의 공개 메타주소만 등록하면, 송금자가 자동으로 일회용 수신 주소를 생성하여 결제할 수 있는 서비스입니다. 매번 새 주소를 만들 필요가 없습니다.

**일반 사용자 경험**:
김하늘씨(32세, 온라인 쇼핑몰 운영자)는 고객들로부터 암호화폐 결제를 받습니다. 예전에는 같은 주소로 받아서 고객들이 그녀의 전체 매출을 볼 수 있었습니다. 이제 쇼핑몰에 스텔스 메타주소를 등록하면, 각 고객이 결제할 때마다 고유한 일회용 주소가 자동 생성됩니다. 고객 A의 결제와 고객 B의 결제는 서로 연결되지 않고, 김하늘씨만이 모든 결제를 확인하고 수령할 수 있습니다.

**관찰 가능한 이점**:
- 고객마다 자동으로 고유한 결제 주소 생성
- 여러 결제 간의 연결 불가능으로 매출 정보 보호
- 주소 관리의 번거로움 없이 프라이버시 확보

## 2. "프리랜서 익명 청구서" - 클라이언트별 분리 결제 서비스

**제품 설명**:
프리랜서가 각 클라이언트에게 서로 다른 결제 주소를 제공하여, 클라이언트들이 서로의 존재나 결제 금액을 알 수 없게 하는 서비스입니다.

**일반 사용자 경험**:
이준호씨(29세, 프리랜서 개발자)는 동시에 5개 회사의 프로젝트를 진행 중입니다. 각 회사에 스텔스 주소 기반의 청구서를 발송합니다. A회사가 결제하는 주소와 B회사가 결제하는 주소는 완전히 다르며, 어느 회사도 이준호씨가 다른 클라이언트로부터 얼마를 받는지 알 수 없습니다. 이준호씨는 협상력을 유지하면서 각 클라이언트와 독립적으로 거래할 수 있습니다.

**관찰 가능한 이점**:
- 클라이언트 간 정보 격리로 협상력 유지
- 전체 수입 규모가 개별 클라이언트에게 노출되지 않음
- 비즈니스 관계의 기밀성 보장

## 3. "후원자 감사 시스템" - 익명 후원 수령 및 감사 표시

**제품 설명**:
크리에이터가 후원을 받을 때 각 후원자에게 고유한 주소를 제공하고, 후원자의 신원은 숨기면서 감사 메시지를 전달할 수 있는 서비스입니다.

**일반 사용자 경험**:
박소연씨(26세, 유튜버)는 팬들로부터 암호화폐 후원을 받습니다. 스텔스 주소 시스템을 사용하면, 각 후원은 고유한 주소로 들어오고, 박소연씨만 누가 후원했는지 확인할 수 있습니다. 팬들끼리는 서로의 후원 금액을 알 수 없어 비교나 경쟁 없이 순수하게 응원할 수 있습니다. 박소연씨는 개인적으로 감사 메시지를 보내면서도 후원자들의 프라이버시를 존중할 수 있습니다.

**관찰 가능한 이점**:
- 후원자 간 금액 비교 불가로 건전한 후원 문화 형성
- 크리에이터만 후원자 정보 확인 가능
- 후원자의 재정 상황이 다른 팬들에게 노출되지 않음
