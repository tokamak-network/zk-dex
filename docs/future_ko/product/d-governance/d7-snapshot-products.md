## 1. "고래 지분 비밀 유지 스냅샷" - 보유량 숨긴 투표 자격 증명

**제품 설명**:
DAO 투표에서 스냅샷 시점의 토큰 보유를 증명하되, 정확한 보유량은 숨기는 시스템. 대형 보유자의 지분 규모가 노출되면 해킹 표적이 되거나, 다른 참여자들이 고래 영향력을 분석하여 전략적으로 행동할 수 있음.

**일반 사용자 경험**:
- DAO 중요 투표, 스냅샷 블록 #15000000 기준
- 박고래씨는 해당 시점에 100만 토큰 보유 (전체의 5%)
- 공개 스냅샷: 정확한 보유량 공개 -> 고래 주소 특정 -> 해킹/사기 표적
- ZK 스냅샷: "스냅샷 시점에 토큰을 보유했음"만 증명, 정확한 양은 비밀
- 투표력은 적용되지만, 외부에서 박고래씨가 얼마나 가졌는지 모름

**관찰 가능한 이점**:
- 대형 보유자 신원/규모 노출로 인한 표적 공격 방지
- 고래 분석 기반 전략적 투표 행위 차단
- 플래시론 공격은 여전히 방지 (스냅샷 기준)

## 2. "과거 보유 익명 증명" - 참여 자격 프라이버시

**제품 설명**:
특정 시점에 토큰을 보유했다는 사실만 증명하고, 현재 보유 여부나 거래 내역은 숨기는 시스템. 과거 참여자임을 증명해야 하지만, 현재 포지션은 비밀로 유지하고 싶은 경우.

**일반 사용자 경험**:
- DeFi 프로토콜 마이그레이션 투표: 기존 사용자만 참여 자격
- 이전사용자씨는 스냅샷 시점에 LP 토큰 보유, 하지만 이후 매도
- 공개 시: "이전사용자씨가 팔았구나" -> 시장 신호, 개인 투자 전략 노출
- ZK 스냅샷: 과거 보유 사실만 증명 - 현재 상태나 거래 이력은 비밀
- 결과: 과거 참여자로서 투표권 행사, 현재 포지션은 프라이버시 유지

**관찰 가능한 이점**:
- 개인 투자/거래 전략 비밀 유지
- 과거 참여 증명과 현재 상태 분리
- 정당한 자격 증명과 프라이버시 동시 달성

## 3. "멀티체인 익명 통합 투표" - 크로스체인 지분 비밀 집계

**제품 설명**:
여러 체인에 분산된 토큰 보유를 증명하되, 각 체인별 보유량이나 총량을 숨기는 시스템. 체인별 분포가 노출되면 투자 전략이나 자금 규모가 드러날 수 있음.

**일반 사용자 경험**:
- 멀티체인 DAO: Ethereum, Arbitrum, Polygon에 토큰 분산
- 김분산씨는 3개 체인에 각각 토큰 보유, 총량은 상당함
- 공개 시: 체인별 분포 분석 -> 자금 규모, 선호 체인, 브릿지 패턴 노출
- ZK 멀티체인 스냅샷: "모든 체인 합산하여 충분한 토큰 보유" 증명, 분포는 비밀
- 결과: 통합 투표력 행사하되 자금 분포 전략은 프라이버시 유지

**관찰 가능한 이점**:
- 크로스체인 자금 분포 패턴 비밀 유지
- 대형 보유자의 멀티체인 전략 보호
- 플래시론 방지와 프라이버시 동시 달성
